Instructions for building and deploying the directory service

Checking out the DS

The directory service uses Git as its version control and the repository is here - /afs/slac/g/cd/swe/git/repos/high_level_apps/directory_service.git. You can use eco to check out the DS; it's project name is directory_service 
[mshankar@lcls-dev2 myworkspace]$ eco   
Enter name of module/package to checkout: directory_service
Enter name of tag or [RETURN] to use HEAD>
Using MAIN_TRUNK. The name of the directory will be MAIN_TRUNK.
....
To check out a tagged release, specify the tag as part of eco.

Building the DS

The DS uses ant requires a 1.8 JDK or later to build. 
[mshankar@lcls-dev2 MAIN_TRUNK]$ java -version
java version "1.8.0_60"
Java(TM) SE Runtime Environment (build 1.8.0_60-b27)
Java HotSpot(TM) Server VM (build 25.60-b23, mixed mode)
[mshankar@lcls-dev2 MAIN_TRUNK]$ ant
Buildfile: build.xml
...
[mshankar@lcls-dev2 MAIN_TRUNK]$ ls jar/simpleDS.jar 
jar/simpleDS.jar
Use ant test to run the unit tests.

Deploying/upgrading the DS

The DS uses cram to upgrade/deploy and is a cram HLA package; the instructions for upgrade/deploy are similar to any other HLA package. 
[mshankar@lcls-dev2 V_0_0_18]$ cram ls
Current version on facility: LCLS  => V_0_0_17
Current version on facility: SPEAR  => None
Current version on facility: FACET  => None
Current version on facility: TestFac  => None
Current version on facility: Dev  => V_0_0_17
[mshankar@lcls-dev2 V_0_0_18] cram push
...
[mshankar@lcls-dev2 V_0_0_18] cram upgrade -f Dev V_0_0_18

Restarting the DS

The DS has standard /etc/init.d scripts to stop/start/restart. It uses Apache Commons Daemon to run as a service. 
[laci@lcls-dev1 ~]$ ps -fade | grep jsvc | grep directory 
laci     18003     1  0 Jan06 ?        00:00:00 jsvc.exec ... edu.stanford.slac.simpleDS.DSMain
laci     18004 18003  0 Jan06 ?        02:52:31 jsvc.exec ... edu.stanford.slac.simpleDS.DSMain

Logs

Logs for the DS are in the ${PHYSICS_DATA}/logs folder. 
[mshankar@lcls-dev2 MAIN_TRUNK]$ ls -la ${PHYSICS_DATA}/log/lcls-dev1_directory_service.log
-rw-rw-r-- 1 laci lcls 17245 Jan 25 10:18 /nfs/slac/g/lcls/physics/log/lcls-dev1_directory_service.log
